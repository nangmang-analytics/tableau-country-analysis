# Tableau Country Analysis

## Project Overview
This is my first Tableau Public project, completed as part of my Data Analytics coursework at Tulsa Community College.

I created two worksheets, Country Overview and Continent Summary, to explore and compare data across countries and continents.

## Skills Demonstrated
- Tableau Public
- Data visualization and text tables
- Sorting and filtering
- Data aggregation using SUM and AVG
- Comparing country-level and continent-level data

## Data Analyzed
- Life expectancy
- Under-five mortality rate
- Internet usage
- GNI per capita
- Population
